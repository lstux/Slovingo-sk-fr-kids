# 🏠 Doma (À la maison)

{{fr:Un terrier, une tanière ou un nid : chacun a son petit chez-soi ! Voici les mots pour parler de la maison et des objets qui s'y trouvent.}}

---

## Les maisons des animaux et les pièces

| Slovenčina | Français |
|---|---|
| dom | la maison |
| nora | le terrier |
| brloh | la tanière |
| hniezdo | le nid |
| izba | la pièce, la chambre |
| kuchyňa | la cuisine |

! Bývam v nore.
> J'habite dans un terrier.

! Maťo býva v brlohu.
> Maťo habite dans une tanière.

! Andrea býva v hniezde.
> Andrea habite dans un nid.

---

## Les meubles et les objets

| Slovenčina | Français |
|---|---|
| posteľ | le lit |
| stôl | la table |
| stolička | la chaise |
| stoličky | les chaises |
| okno | la fenêtre |
| okná | les fenêtres |
| dvere | la porte |
| kniha | le livre |
| knihy | les livres |
| lampa | la lampe |
| lampy | les lampes |

| hračky | les jouets |

! Kde je moja kniha?
> Où est mon livre ?

! Kniha je na stole.
> Le livre est sur la table.

---

## Où ? Ici ou là-bas ?

| Slovenčina | Français |
|---|---|
| kde | où |
| čo | quoi |
| v | dans |
| na | sur |
| tu | ici |
| tam | là-bas |
| blízko | tout près |

! Čo je na stole?
> Qu'est-ce qu'il y a sur la table ?

! Lampa je v izbe.
> La lampe est dans la chambre.

---

## Quelques nombres et sensations

| Slovenčina | Français |
|---|---|
| dva / dve | deux |
| tri | trois |
| štyri | quatre |
| teplo | chaud |
| zima | froid |

! V brlohu je teplo.
> Dans la tanière, il fait chaud.

! Na posteli sú dve hračky.
> Sur le lit, il y a deux jouets.

## Petit truc

{{fr:En slovaque, le mot change parfois un peu après}} {{v}} {{fr:et}} {{na}}{{fr:. Pour commencer, retiens les expressions entières :}}

- {{v nore}} = dans un terrier
- {{v brlohu}} = dans une tanière
- {{v hniezde}} = dans un nid
- {{na stole}} = sur la table
- {{na posteli}} = sur le lit
