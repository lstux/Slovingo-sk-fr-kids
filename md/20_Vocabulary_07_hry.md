# ⚽ Hry (Les jeux)

{{fr:Dans une prairie des Tatras, on peut jouer au ballon, à cache-cache ou au jeu du chat. Voici les mots pour jouer ensemble !}}

---

| Slovenčina | Français |
|---|---|
| hra | le jeu |
| lopta | le ballon |
| skrývačka | le cache-cache |
| naháňačka | le jeu du chat |
| lúka | la prairie |
| strom | l'arbre |

---

## Jouer ensemble

| Slovenčina | Français |
|---|---|
| hrám sa | je joue |
| hráš sa | tu joues |
| hráme sa | on joue / nous jouons |
| hrať sa | jouer |
| môžem | je peux |
| môžeš | tu peux |
| môžeme | on peut / nous pouvons |
| nemôžem | je ne peux pas |
| nemôžeš | tu ne peux pas |
| nemôžeme | on ne peut pas |

! Hráme sa!
> On joue !

! Môžem sa hrať?
> Je peux jouer ?

---

## C'est à qui ?

| Slovenčina | Français |
|---|---|
| na rade | au tour de… |
| teraz | maintenant |
| už | ça y est |
| ťa | te |
| kde si? | où es-tu ? |
| tu som | me voici |
| nevidím ťa | je ne te vois pas |

! Kto je na rade?
> C'est à qui ?

! Tu som!
> Me voici !

## Gagner, perdre et recommencer

| Slovenčina | Français |
|---|---|
| hľadať | chercher |
| počítam | je compte |
| vyhrávam | je gagne |
| prehrávam | je perds |
| vyhráva | il / elle gagne |
| zábava | le plaisir, l'amusement |
| ešte raz | encore une fois |
| hurá | hourra |
| spolu | ensemble |
| dobrá hra | bien joué |

! Ešte raz!
> Encore une fois !

! Hráme sa spolu!
> On joue ensemble !

! Dobrá hra!
> Bien joué !

+ {{hrám sa}}, {{hráš sa}} et {{hráme sa}} veulent tous dire « jouer », mais pas avec la même personne : je, tu, nous/on.
